# Minecraft Skin 樣式轉換器 v6

在瀏覽器內為 Minecraft Skin 套用圖案，比較原始和轉換後的 2D／3D 預覽，再下載 PNG。網站可離線使用，圖片全程在你的裝置上處理。

## 快速啟動

1. 從 GitHub 的 **Code → Download ZIP** 下載專案並解壓縮，或使用 Git 複製 repository。
2. 用瀏覽器打開 `index.html`。直接開啟時無需安裝 Python 或其他套件。
3. 上傳或拖入 PNG，勾選要套用的圖案，按下轉換，再下載輸出。

若要以本機伺服器啟動，請安裝 Python 3。Windows 可雙擊 `start.bat`，也可在專案目錄執行：

```powershell
py -3 server.py
```

在 macOS 或 Linux 上，執行 `python3 server.py`。程式會在瀏覽器開啟本機網址，並在終端機顯示所用的連接埠（5500–5510）。按 Ctrl+C 停止伺服器。

## 轉換選項

| 選項 | 套用圖案 |
| --- | --- |
| 下巴 | 套用頭部底面原有的 14 個像素筆畫。 |
| 屁股 | 以範例配色覆蓋身體底面 8×4，共 32 個像素。 |
| 蝦尾臉 | 套用臉部正面的 13 個像素，保留頭部外層。 |

三個選項可單獨或一起套用。支援 64×64、64×32，以及這兩種尺寸的等比例整數倍 PNG，例如 128×128 或 128×64。

## 3D 預覽

- 拖曳可 360° 旋轉，滾輪可縮放，也可重設視角。
- 可切換原始／轉換後的 Skin，以及 Steve 標準手臂／Alex 纖細手臂。
- 10 個顯示開關控制頭部外層、身體外層、手部外層、腿部外層，以及頭、身體、左手、右手、左腿、右腿。開關只影響預覽。
- 64×32 舊版 Skin 的左右手腳會鏡像顯示。3D 預覽需要 WebGL，PNG 轉換及下載可獨立使用。
- v6 校正 3D 模型底面的紋理方向。下巴圖案朝向臉部前方，屁股圖案朝向角色背面，沿用原有 PNG 轉換座標。

## 專案檔案

- `index.html` 包含網站介面、PNG 轉換與 WebGL 預覽。
- `server.py` 和 `start.bat` 提供本機伺服器啟動方式。
- `sample-*.png` 是原版專案附帶的轉換範例與參考圖。
